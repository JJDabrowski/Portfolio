## Context

There are some functions that are used in the main.py as commands. They are larger and more important than the others

## Considered Options

* define the functions in `main.py`
* define the functions in `parser_utils/support_funcs`
* create another file for these functions

## Decision Outcome

Chosen option: create another file for these functions. They are an important part of this app and as such should be treated separately
